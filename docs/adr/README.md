# Architecture Decision Records

Architecture Decision Records (ADRs) document the significant decisions made in Reed's design — the context, the options considered, the decision taken, and the consequences.

Each ADR is immutable once accepted. If a decision is reversed, a new ADR supersedes it rather than editing the original.
